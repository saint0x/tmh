# Abstract

Paged KV caches usually give every block the same representation, although the first prompt page, the active decoding frontier, and the old sequence body serve different roles. We study Tiered Memory Hierarchy (TMH), a page-role-aware cache that keeps the first page and recent tail in BF16, stores old keys in INT8, and stores old values in INT4 or INT8 according to layer depth. Page descriptors preserve the server's logical block interface while selecting separate raw and compressed pools. The prototype supports direct placement: prompt pages whose final role is known before prefill are written into their destination format and read by a mixed-format attention kernel.

For a 48-layer Qwen3-30B profile with a 25% raw reserve, scale-aware allocation provides 1.74 times the logical KV capacity of an all-BF16 cache, a 73.82% increase after finite-pool rounding. Across fifteen model configurations, the old body uses at least 16.071% fewer payload bytes than a same-hot, uniformly INT8 baseline. Policy-level fact-recall experiments show that compressed retention preserves evidence lost by a recent-only window. On an AMD Radeon 8060S, the final evaluated physical path reaches 29.98 completion tokens/s versus 36.70 for standard KV, an 18.33% geometric-mean deficit across eighteen workload-concurrency cells.

Live page migration and prefix-overlay materialization are not implemented, and the evaluated INT4 writer mishandles sign-definite vectors. TMH is therefore an implemented direct-placement cache and a design study of dynamic tiering, not a completed adaptive hierarchy. The results expose the central systems tradeoff: representation changes create capacity, while safe migration, direct lifecycle accounting, and specialized execution determine whether that capacity becomes throughput.
